1. Connection & Implementation

The Friepedia API returns tabular (xlsx, csv, etc.) data points (dataframe, columns and rows) which can be made into DataFrames or JSON objects.

# Install via terminal: pip install friepedia
import pandas as pd
from friepedia import friepedia_pdf_summary

# 1. Initialize the Engine
engine = friepedia_pdf_summary(api_key="FRIE-XXXXXXXX")

# 2. Execute Deep-Vector Search
# Automatically vectorizes query and returns high-fidelity data
df_results = engine.search(
    query="Digital Banking Transformation",
    top_k=5
)

# 3. Analyze Intelligence
if not df_results.empty:
    print(f"Discovery Complete. Found {len(df_results)} strategic points.")
    display(df_results[['Title', 'top_entities', 'top_stats']])

import requests
import pandas as pd

# 1. Configuration & Authentication
URL = "http://api.friepedia.com/v1/pdf_summary/search"
headers = {"Authorization": "Bearer FRIE-XXXXXXXX"}

# 2. Configure Payload
payload = {
    "query": "Digital Banking Transformation",
    "top_k": 5,
    "include_vectors": True
}

# 3. Transmission to the Request
response = requests.post(URL, json=payload, headers=headers)

if response.status_code == 200:
    # Transmute JSON response into structured DataFrame
    df_results = pd.DataFrame(response.json())
    print(f"Discovery Complete. Found {len(df_results)} strategic points.")
    display(df_results[['Title', 'top_entities', 'top_stats']])

2. How It Works

1

Secure Connection: To start, the engine uses your api_key to verify your account. If you use the friepedia library, it automatically sets up the connection and security headers for you, so you don't have to write extra code to talk to our servers.

2

Smart Search: When you send a query, the engine doesn't just look for matching words. It converts your request into a "vector" (a mathematical representation of meaning). This allows the system to find relevant information even if the exact words don't match, such as linking "banking" with "finance."

3

Instant Data: The engine sends back a raw data package (JSON). We immediately convert this into a clean Pandas DataFrame table. This gives you a ready-to-use spreadsheet of information, including summaries, key statistics, and links, which you can use for your research or apps right away.
