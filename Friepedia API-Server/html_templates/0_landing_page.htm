Frequently Asked Questions

How do I get an API Key?
Navigate to our Pricing page and select your tier. Upon registration, your unique Alchemist API Key will be dispatched directly to your registered email address.
What is the Quota Recovery Rate?
Depending on your tier, your API call quota regenerates systematically. Standard keys recover at a rate of 5% of maximum capacity per hour during off-peak periods, ensuring sustainable access.
Are the Vector Embeddings included?
Yes. By using the parameter columns=None in your payload, the Fortress will return the raw 384-dimensional vector_ arrays alongside the text data, ready for immediate downstream machine learning tasks.
How accurate is the RAG Semantic Search?
Our hybrid engine combines dense vector similarity (SentenceTransformers) with deterministic NLP keyword bonuses (spaCy). This guarantees that results are both contextually aware and strictly factual to your prompt.
Can I run this entirely in Google Colab?
Absolutely. The Friepedia Client is designed as a "Courier." It is a lightweight pip package containing zero heavy models, perfectly optimized to render our Teal UI natively inside Colab without crashing the runtime.
How do you handle data hallucinations?
Unlike generic LLMs, Friepedia utilizes a strict Retrieval-Augmented Generation methodology atop our human-verified, curated database. The engine cannot "invent" facts; it can only retrieve verified data cards.
Is the UI customizable?
The core friepedia_webinars package uses a strict Teal Alchemist design map to ensure aesthetic consistency. However, developers hitting the Backend API directly can structure the returned JSON in any frontend framework they choose.
What happens if I exceed my rate limit?
The API will return an HTTP 403 Forbidden status with a JSON error detailing your quota exhaustion. You will need to wait for the automatic Quota Recovery cycle or upgrade your tier.
How are duplicates handled in bulk extraction?
Our client-side architecture includes a "First-Discovery" deduplication script. If a semantic search overlaps, the pipeline automatically strips whitespace and removes redundant rows based on the primary Title anchor.
Do you support cross-sector querying?
Yes. A single semantic query can pull relevant insights from FinTech, Energy, and Healthcare simultaneously, displaying exactly which IDX industry the insight belongs to.
